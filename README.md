# Ranking da Equipe

Aplicação React/Vite para exibir o ranking dos jogadores e um gráfico de estrelas.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Verificação

```bash
npm run lint
npm run build
```

Os dados de demonstração estão em `src/mock/players.ts`. Cada jogador tem uma posição única e uma pontuação de 0 a 5 estrelas.
